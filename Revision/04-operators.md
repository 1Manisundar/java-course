# Operators

## Arithmetic
`+  -  *  /  %`

`%` gives the remainder. Integer division removes the decimal part.

```java
10 / 3 // 3
10 % 3 // 1
```

## Assignment
`=` assigns a value.

## Comparison
`==  !=  >  <  >=  <=`

`=` assigns; `==` compares.

## Logical
`&&` = AND, `||` = OR, `!` = NOT

## Increment / Decrement
`x++`, `++x`, `x--`, `--x`

Post-increment uses the old value first. Pre-increment increments before using the value.
